# 🐤 Flappo Bort

**Flappo Bort** es un clon del clásico **Flappy Bird**, desarrollado en **Unity**. Vuela entre los tubos, evita obstáculos y alcanza la mejor puntuación que puedas.

## 🎮 Características

- Jugabilidad inspirada en el original Flappy Bird
- Diferentes Skins a elegir
- Física personalizada para un control fluido
- Sistema de puntuación

## 🛠️ Requisitos para jugar

No necesitas instalar nada si recibes la versión compilada.

### ✅ Jugador

Si alguien te envía una **build compilada** (por ejemplo, para Windows):

- Descomprime el archivo `.zip` que te compartan
- Ejecuta el archivo `FlappoBort.exe`
- ¡Y a jugar!
